# AI Heritage Dictionary
An AI-powered Heritage Language Translator and Dictionary platform designed to document, preserve, and promote endangered Indian languages such as **Tulu** and **Kodava**.
This project aims to combine Natural Language Processing (NLP), community contributions, and modern web technologies to build a digital ecosystem for low-resource languages.

---

## Problem Statement

Many regional languages in India are at risk of extinction due to limited digital resources and declining everyday usage.

This project focuses on:

- Preserving endangered languages
- Providing AI-assisted translation
- Building a searchable community dictionary
- Collecting linguistic data from native speakers
- Supporting future research in low-resource NLP

## API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | `/api` | API status |
| POST | `/translate` | Translate text |
| GET | `/dictionary/search` | Search dictionary |
| GET | `/dialects` | List supported dialects |
| POST | `/contribute` | Submit new words or sentences |
| GET | `/contribute/count` | View contribution count |
